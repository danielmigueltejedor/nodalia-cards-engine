# Security policy

## Supported versions

Security fixes are provided for the latest published release of Nodalia Cards Engine.

## Reporting a vulnerability

Please use GitHub's private **Report a vulnerability** flow for this repository. Do not include access tokens, Home Assistant backups, notification contents or entity inventories in a public issue.

Include the Engine version, Home Assistant version, affected capability and the minimum reproduction steps. Reports will be acknowledged as soon as possible and coordinated privately until a fix is available.
